Model site logins

Browsing works without these. Downloads from Nexprint and MakerWorld need your login token from the website (see the help under each box). Printables needs nothing (except for its adult models).

Nexprint
On nexprint.com while logged in: browser menu → Developer tools → Application → Cookies → auth_token.
MakerWorld
On makerworld.com while logged in: Cookies → token.
Thingiverse
Create an app at thingiverse.com/developers and copy its App Token.
Cults3D
Logged in on cults3d.com, open cults3d.com/en/api/keys, create a key, and paste yourusername:thekey. Cults3D's API gives search and details; most files are downloaded on its website.
Printables
Only for adult models: Printables hides them unless you're logged in and have adult content turned on in your Printables settings.
How to get it (on a PC, about a minute): log in on printables.com in Chrome or Edge, press F12, open the Network tab, type graphql in its filter box, then reload the page. Click any graphql line, find authorization under Request Headers, and copy its value (it starts with Bearer). Paste it here; the word Bearer can stay. It stops working when Printables logs you out; just paste a fresh one.
